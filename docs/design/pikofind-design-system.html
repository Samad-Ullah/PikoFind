What guides every pixel

Five promises to the child

A four-year-old must play without reading. These principles outrank any visual flourish.

Audio first

Every instruction is spoken. Text is for grown-ups only.

One clear action

The child always knows the single thing to do next.

Kind feedback

A wrong tap is “Good try, look again!” — never a red cross.

Fast sessions

Roughly five finds, then a celebration. No long commitment.

Offline & private

No account, no camera, no data. It all stays on the phone.

Mascot

Meet Piko

A small, round, never-judgy parrot. Teal body, sunshine wings, a coral beak and big kind eyes. Ten states, built from one shape with simple transforms — no heavy frame-by-frame art.

CuriousPatientEncouraging PlayfulNever judgmentalShort sentences

Export as static SVG poses; animate with scale / rotate / translate only. A two-to-four-frame sprite is the ceiling — no GIF, no video, no giant Lottie.

Components

Chunky, rounded, outlined

Thick navy outlines, soft static drop shadows, big touch areas. No glassmorphism, blur or thin borders.

KidButton

Pill shape · 3px navy border · pressed = drops onto its shadow.

IconButton

Round · labelled for grown-ups · ≥ 60×60.

ProgressDots — “find 3 of 5”

The only “score” a child sees: five gentle dots, current one enlarged.

Stickers & rewards

Earned = full colour · locked = grey silhouette. Deterministic, never a loot box.

Layout & responsive

One landscape canvas, everywhere

Safe area & letterboxing

Baseline 1280×720 (16:9). Scale proportionally, letterbox on taller screens, centre on tablets — never stretch.

safe play area

Normalized object coordinates

Objects store 0–1 positions, not pixels — so every screen above places art the same way the engine will.

{
  id: "red_ball",
  position: { x: 0.22, y: 0.66 },
  dimensions: { width: 0.15, height: 0.20 },
  hitboxPadding: 0.03
}

Keep targets clear of edges, gesture zones, other objects and Piko’s bubble. Distinguish by shape as well as colour.
